# Marcus Rummler Instructional Design Portfolio

Static portfolio site for Marcus Rummler, Senior Instructional Designer and learning technology builder.

## Local Preview

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8081
```

Then visit `http://localhost:8081`.

## Deployment

This folder is intended for GitHub Pages. Publish from the repository root using the `main` branch and `/` folder.

## Notes

Before public deployment, review the CV and client screenshots for contact-detail and confidentiality comfort.
